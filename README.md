# QR Code Generator

This is a **QR Code Generator** application built with **Python** and **HTML**. The application allows users to generate QR codes from provided text or URLs.

## Features

- Generate QR codes from text or URLs  
- Simple, user-friendly interface built with **HTML**  
- Backend powered by **Python**  
- QR code generation using the **qrcode** Python library  

## Tech Stack

- Python  
- HTML  
- **qrcode** Python library
